# Project Summary
Reading Companion is an AI research assistant for students and researchers who want to understand arXiv papers and trace answers back to sources. Users provide a research goal and optionally a paper ID or link. The agent plans research, searches and reads papers, records sourced notes, answers with citations, and checks its claims.

Completed sessions can be saved, browsed in a recent-questions gallery, and shared through session links. The interface now follows the Repro Suite design system, with a responsive sidebar, light and dark themes, and English and Chinese controls.

# Project Module Description
- **Research agent:** Runs in the browser and uses the LLM gateway and paper-tools service for paper search, abstract lookup, full-text reading, and sourced notes. Displays plans, tool calls, notes, answers, and self-checks in a live timeline, with a maximum of 12 turns.
- **Evidence and citations:** Notes include a paper ID and a quote of up to 25 words. The interface checks quote support and distinguishes full-text evidence, abstract-only evidence, and unsupported quotes. Answers use numbered arXiv citations and identify unverifiable claims.
- **Session management:** Saves completed goals, answers, notes, and token counts to the `reading_sessions` database table. Includes a recent-questions gallery and shareable session pages.
- **Navigation and appearance:** Repro Suite sidebar links to existing app sections and external suite apps. At widths under 900px, the sidebar becomes a drawer. Light and dark themes are available, with the preference stored in `localStorage` under `repro.theme2`.
- **Internationalized interface:** English and Chinese UI toggle, with answers in the selected language. Responsive layouts support mobile screens.
- **Authentication and backend services:** FastAPI modules provide authentication, user, settings, storage, AI hub, health, and session APIs. The research agent calls the supplied LLM and paper services directly; secrets are not stored in the frontend.

# Technology Stack
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, and reusable UI components.
- **Backend:** Python, FastAPI, SQLAlchemy, and Alembic.
- **Research services:** LLM gateway and arXiv paper-tools service, called directly by the browser.
- **Data:** Atoms Cloud database, using the `reading_sessions` table.
- **Design:** Inter, Noto Sans SC, and JetBrains Mono; responsive light and dark themes.
- **Quality and rendering:** ESLint, Playwright configuration, Vite plugins, and blog prerendering.

# Usage
- Install frontend dependencies from `app/frontend` with `npm install`.
- Start the frontend development server with `npm run dev`; create a production build with `npm run build`.
- Install backend dependencies in a Python environment with `pip install -r requirements.txt` from `app/backend`.
- Use `app/start_app_v2.sh` to start the application when its required environment and service configuration are available.
- Configure database and service settings for the deployment environment. Keep secrets out of frontend code.
- Apply database migrations using the project’s Alembic configuration when setting up or updating the database.
